# Diwali Sales Analysis (EDA)

## Overview
Exploratory data analysis of Diwali sales data to identify customer purchasing behavior and sales trends.

## Objective
- Understand customer demographics and buying patterns
- Identify top-performing product categories and regions

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Key Insights
- Female customers contributed higher sales
- Age group 26–35 showed highest purchase activity
- Married customers spent more during Diwali

## Conclusion
Insights from this analysis can help businesses improve festive marketing strategies and optimize sales performance.
